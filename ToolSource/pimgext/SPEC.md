# pimgext 仕様

吉里吉里系ゲームの `.pimg`（PSB 形式のレイヤー画像コンテナ）を解凍し、
あわせて「ベース画像＋差分画像」を合成した PNG を出力するコマンドラインツール。

## 1. 動作環境

- Python 3.8 以上（標準ライブラリのみ。numpy / Pillow 等は使わない）
- Linux / Windows / macOS

## 2. コマンドライン

```
pimgext [オプション] 入力...
```

| 引数 / オプション | 説明 |
|---|---|
| `入力...` | `.pimg` ファイル、またはディレクトリ（直下の `*.pimg` を処理。再帰しない）。複数指定可 |
| `-o, --output DIR` | 出力先の親ディレクトリ。省略時は各 `.pimg` と同じディレクトリ |
| `--no-composite` | 合成を行わず `raw/` のみ出力する |
| `-f, --force` | 出力先フォルダが既にある場合も上書きする（省略時はそのファイルをスキップして警告。スキップは失敗扱いにしない）。同名ファイルを上書きするだけで、既存の他のファイルは消さない |
| `-q, --quiet` | 警告を表示しない（エラーは表示する） |

### 終了コード

| コード | 意味 |
|---|---|
| 0 | すべての入力を処理できた（警告があっても 0） |
| 1 | 1 つ以上の入力が処理できなかった（他の入力の処理は続行する） |
| 2 | 引数の誤り |

## 3. 出力構成

`sample.pimg` を処理すると、同じ場所（または `-o` の場所）に次を作る。

```
sample/
  ├─ raw/
  │   ├─ 2.tlg, 3.tlg, ...    PIMG 内のバイナリをそのまま書き出したもの
  │   └─ sample.json          PSB ツリー全体
  └─ composite/
      ├─ Aa.png               ベース単体
      ├─ Aa+Ab.png            ベース＋差分
      └─ ...
```

### 3.1 raw/

- ルート辞書のうち値がバイナリのものを、**キー名をファイル名として**そのまま書き出す（例: `2.tlg`）。
- `sample.json` は PSB ツリー全体を JSON 化したもの（UTF-8, インデント 2）。
  - バイナリ値は、書き出したファイル名の文字列に置き換える（ルート直下以外のバイナリは `"<binary:番号>"` とし、`raw/_bin<番号>.bin` として書き出す）。
  - 数値・文字列・真偽値・null・配列・辞書はそのまま出力する。キーの順序は PSB 内の順序を保つ。
- raw/ は合成の成否に関係なく**常に出力する**。

### 3.2 composite/

- PNG（8bit RGBA）。サイズはルートの `width` × `height`。
- ファイル名は `layers[].name` を使う。ファイル名に使えない文字は `_` に置き換える。名前が重複する場合は `<name>_<layer_id>`、空の場合は `layer_<layer_id>` とする。
- ベースがキャンバスより小さい場合、覆われない部分は透明になる。

## 4. 入力形式

| 形式 | 判定 | 扱い |
|---|---|---|
| 平文 PSB (v2 / v3) | 先頭 `PSB\0` | そのまま読む |
| mdf 圧縮 | 先頭 `mdf\0` | `+4` の 4 バイト（LE）が展開後サイズ、`+8` 以降を zlib 展開してから PSB として読む |
| 暗号化 PSB | ヘッダの Flag の bit0 / bit1、またはルートコードが `0x21` でない | **エラー**（その入力をスキップ、終了コード 1） |
| 上記以外 | — | エラー |

PSB の読み方は `KrkrExtract/KrkrExtract.Core/PsbWorker.cpp`（`PsbArray` / `PSBNode` / `ProbeDictName` 等）に従う。ただしヘッダのオフセットはポインタではなく 32bit 整数として扱う。

## 5. 画像デコード

- TLG5（`TLG5.0\0raw\x1a`）: デコードして合成に使う。
- TLG6 / その他: 合成に使えないため、そのレイヤーは合成時にスキップして警告する（raw/ には出力される）。

## 6. 合成ルール

前提とする形式（サンプル `ev101_a.pimg` で確認済み）:
全面を覆うベース 1 枚と、互いに排他の差分（表情パーツ等）複数枚からなる。

1. **ベースの決定**: `layers` のうち、`left == 0` かつ `top == 0` かつ `width`/`height` がキャンバスと同じで、全ピクセル不透明のもの。
   - 候補が複数ある場合は `layers` の末尾に近いもの（最下層）を使う。
   - 候補がない場合は `layers` の末尾の要素をベースとして扱い、警告する。
2. **差分**: ベース以外で画像を持つレイヤーすべて。
3. **出力**: ベース単体 1 枚と、差分ごとに「ベース＋その差分 1 枚」を 1 枚ずつ出力する。差分同士は重ねない。
4. **重ね方**: 差分画像を (`left`, `top`) に置き、ピクセルのアルファに `opacity / 255` を掛けて通常のアルファ合成（吉里吉里の `ltPsNormal`）を行う。キャンバス外にはみ出す部分は切り捨てる。
5. `visible` は無視する（非表示の差分も出力する）。

### 6.1 前提に合わない場合

処理は止めずに、上記のルールのまま合成して出力する（結果の画像が正しくない可能性がある）。次の場合は標準エラーに警告を出す。

| 状況 | 動作 |
|---|---|
| ベースの条件を満たすレイヤーがない | 末尾のレイヤーをベースにして続行 |
| `type` が 13（`ltPsNormal`）以外 | 通常のアルファ合成として続行 |
| `layer_type` が 0 以外（グループレイヤー等） | 画像があれば差分として扱い、なければスキップ |
| レイヤーに対応する `<layer_id>.tlg` がない | そのレイヤーをスキップ |
| 画像サイズが `width`/`height` と違う | 画像の実サイズで続行 |
| TLG5 以外の画像 | そのレイヤーをスキップ（§5） |
| `layers` がない | 合成を行わず raw/ のみ出力 |
| ルートに `width`/`height` がない | レイヤーの範囲からキャンバスサイズを求めて続行 |

警告の形式: `pimgext: warning: <ファイル名>: <内容>`

## 7. 範囲外（行わないこと）

- 暗号化 PIMG の復号（E-mote 秘密鍵）
- 差分同士の組み合わせ（服＋表情など同時に重ねるもの）の自動判定
- `ltPsNormal` 以外のブレンドモードの正確な再現
- グループレイヤーの階層合成
- `.pimg` への再パック

## 8. 確認方法

```bash
python3 ToolSource/pimgext/pimgext.py ev101_a.pimg
```

- リポジトリ直下の `ev101_a.pimg` で、raw/ に 8 個の TLG と JSON、composite/ に 8 枚の PNG（`Aa.png` と `Aa+Ab.png` 〜 `Aa+Ah.png`）が出力され、警告が出ないこと。
